# ⏰ Python Digital Clock

A simple and lightweight **Digital Clock application** built using **Python Tkinter**.  
It displays the current **time and date** in real-time with a clean graphical interface.

---

## 🚀 Features

- Real-time digital clock
- Displays current time (HH:MM:SS)
- Displays current date (DD-MM-YYYY)
- Clean and minimal GUI
- Beginner-friendly Python project
- Uses Tkinter (built-in Python library)

---

## 🧠 Tech Stack

- Python 3.10+
- Tkinter (GUI)
- time module
